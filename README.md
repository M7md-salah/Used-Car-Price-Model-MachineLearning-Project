## 📌 Overview
This project was developed as the final capstone for the **Introduction to Machine Learning** bootcamp at **Orange Digital Center (ODC)**. The primary goal is to predict the price of used cars in Egypt based on various historical and technical features, providing a data-driven pricing tool for the local market.

*🏆 Graduated with a final grade of 98.60% (35-Hour Bootcamp)*

## 📊 Dataset & Features
The model is trained on a dataset reflecting the Egyptian automotive market. Key features analyzed include:
* `Brand & Model`
* `Year of Manufacture`
* `Kilometers Driven`
* `Engine Capacity (CC)`
* `Transmission Type`

## ⚙️ Machine Learning Pipeline
1. **Data Preprocessing & Cleaning:** Handled missing values, removed outliers, and applied encoding for categorical variables (e.g., Car Brands, Transmission).
2. **Exploratory Data Analysis (EDA):** Visualized correlations between car prices, age, and mileage to understand market depreciation trends.
3. **Model Training:** Implemented and compared multiple regression algorithms to find the best fit.
4. **Model Evaluation:** Evaluated performance using standard metrics (RMSE, R² Score) to ensure prediction reliability.

## 🚀 Results
The final model successfully identified the most critical factors influencing car prices in Egypt, offering highly accurate price estimations that can assist both buyers and sellers in making informed decisions.
